بناء ملف APK:
1) ثبّت Android Studio (مجاني).
2) File > Open ثم اختر هذا المجلد KhuzabilatApp وانتظر انتهاء المزامنة (Gradle Sync).
3) من القائمة: Build > Build Bundle(s) / APK(s) > Build APK(s).
4) سيظهر لك رابط locate، وفيه الملف app-debug.apk. انقله إلى هاتفك وثبّته (فعّل تثبيت التطبيقات من مصدر غير معروف).
ملاحظة: خطوط أميري تُحمَّل من الإنترنت عند توفره، وبدونه يُستعمل خط النظام.
